# What is certain, what is deduced, what is guessed

The emulator tries to be faithful to the machine, but many documents have been lost. So every detail carries one of three labels:

- **CERTAIN** — stated explicitly in a period source or seen in a photograph;
- **DEDUCED** — follows logically from the sources but is not written down (for example the order of execution, confirmed by the original programs);
- **GUESSED** — needed for it to work, without a source; to be replaced when the right document turns up.

An explanation can also carry the label **CERTAIN / DEDUCED / GUESSED, in parts**, when it mixes facts of different status; the text then says which part is which. (In the Romanian sources and code the labels are SIGUR, DEDUS and GHICIT.)

## Where the labels appear
- in the explanations of the **Explain** button, on every element;
- in the provenance label of the chosen program;
- in the chapters of this documentation;
- in the source code, as `// GHICIT:` and `// DEDUS:`.

## The full table
The list of every choice, with the reason for each, is in the project document **[Emulator semantics](doc.html?lang=en#semantica)**: the word and the instructions, timing, shifts, peripherals, the console, the micro-operations, the checks against the original programs and the choices of the web page.

## What is missing
Lab sheets 1–6 and the lost pages of sheets 7–8 (Baltac published them online; the web archive kept only a few pages) would settle much of what is now guessed: shifts, multiplication and division, the character codes, the ICR automaton, timing. Any document or close-up photograph of the console helps.
